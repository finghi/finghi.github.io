# 个人简介网站

这是一个基于HTML、Tailwind CSS和JavaScript构建的现代化个人简介网站，展示个人信息、技能、项目和联系方式。

## 网站特点

- **响应式设计**：完全适配移动端、平板和桌面端
- **现代化UI**：使用Tailwind CSS v3构建的美观界面
- **交互体验**：丰富的动画和过渡效果
- **性能优化**：懒加载、CSS优化等性能提升措施
- **语义化HTML**：良好的代码结构和SEO支持

## 技术栈

- HTML5
- Tailwind CSS v3
- JavaScript (原生)
- Font Awesome (图标库)

## 网站结构

- **导航栏**：网站主要部分的快速链接
- **英雄区域**：个人头像和简短介绍
- **关于我**：详细的个人背景和经历
- **技能**：专业技能和熟练度展示
- **项目**：代表性项目展示
- **工作经历**：职业发展时间线
- **联系我**：联系方式和表单

## 如何使用

1. 将仓库克隆到本地：
   ```bash
   git clone https://github.com/finghi/finghi.github.io.git
   ```

2. 打开 `index.html` 文件即可在浏览器中查看网站

## 自定义

要自定义网站内容，请编辑 `index.html` 文件中的以下部分：

- 个人信息和头像
- 技能和经验数据
- 项目展示内容
- 联系方式

## 部署

该网站可以直接部署到GitHub Pages：

1. 确保仓库名为 `username.github.io`（已设置）
2. 推送到GitHub后，在仓库设置中启用GitHub Pages
3. 网站将自动部署在 `https://finghi.github.io`
